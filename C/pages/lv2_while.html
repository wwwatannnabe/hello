while文（条件付き繰り返し処理）

概要

条件式が真（成り立つあいだ）ずっと処理を繰り返すための構文だよ。
あらかじめ回数が決まっていない処理に向いてるよ。

処理の流れ（図解）

基本の書き方と例

#include <stdio.h>

int main(void) {
    int count = 3;

    // count が 0 より大きいあいだ繰り返す
    while (count > 0) {
        printf("残り %d\n", count);
        count--; // 条件が変化するように更新する
    }

    printf("終了！\n");
    return 0;
}
残り 3
残り 2
残り 1
終了！
