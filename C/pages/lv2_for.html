Lv.2 基礎

for文（繰り返し処理）

概要

同じ処理を決まった回数だけ繰り返すための構文だよ。
「①最初の準備」「②続ける条件」「③1回ごとの変化」の3つを1行にまとめて書けるよ。

処理の流れ（図解）

基本の書き方と例

#include <stdio.h>

int main(void) {
    // ① iを0で開始 / ② iが3未満なら続ける / ③ 1回ごとにiを1増やす
    for (int i = 0; i < 3; i++) {
        printf("%d回目の実行\n", i + 1);
    }
    return 0;
}
