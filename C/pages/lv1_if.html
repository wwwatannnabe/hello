条件分岐（if文 / switch文）

if文：条件が成り立つときだけ動く

条件式が真（成り立つ）ときだけ処理を実行する基本の分岐だよ。
「もし〜ならA、そうでなければB」のように、範囲や条件式で道筋を分けられます。

#include <stdio.h>

int main(void) {
    int score = 75;

    if (score >= 80) {
        printf("合格（優秀）\n");
    } else if (score >= 60) {
        printf("合格\n");
    } else {
        printf("不合格\n");
    }

    return 0;
}
合格

switch文：値ごとに処理を振り分ける

1つの変数や式の値（整数や文字など）に応じて処理を分岐する構文だよ。
「== で特定の値と一致するか」を何通りも判定したいとき、if - else if よりスッキリ書けるよ。

#include <stdio.h>

int main(void) {
    int menu = 2;

    switch (menu) {
        case 1:
            printf("コーヒーを選びました\n");
            break;
        case 2:
            printf("紅茶を選びました\n");
            break;
        default:
            printf("該当する番号がありません\n");
            break;
    }

    return 0;
}
紅茶を選びました
